# Architectural Decisions & Risk Register

## Plan (Web Stack Override)
1. Static web app: plain HTML + CSS + ES modules (`index.html`, `css/style.css`, `js/...`), served via `python -m http.server 8000` (no build step, no npm, no CDN).
2. Inline SVG for board (`1050×1150`) and 14 pieces (`120×120` `<symbol>` + `<use>`), matching DESIGN.md §§5–6.
3. Subset LXGW WenKai TC (fallback Noto Serif TC) via `pyftsubset` into `assets/fonts/` with OFL license; wait for `document.fonts.ready` before first render.
4. Implement model (`Board`, `Piece`, `Pos`, `Move`, FEN, undo) + `RulesProvider`/`PermissiveRules` + `Engine` stub + unit tests (`node --test` or browser test runner).
5. Build `BoardView` (Pointer Events, click-click + drag, lift/slide/capture/flip/undo tweens, keyboard shortcuts) and `SidePanel` (player cards, move list, captured trays, buttons, modal).
6. Add second theme "Ngọc Bích" with 200 ms cross-fade, HiDPI verification, `?gallery` and `?preview` modes, and visual review against DESIGN.md §14.

## Top 5 Risks & Mitigations (Prompt 0)
1. **SVG `feTurbulence` wood grain appearance & performance**: `fractalNoise` can band, look too harsh, or lag during flip/resize. *Mitigation*: tune `feColorMatrix` and opacity (`0.28`), verify in Chrome screenshots, and isolate transforms; fall back to layered SVG gradients only if filters misbehave.
2. **Calligraphic glyph optical centering & FOUT**: `dominant-baseline` varies across fonts/browsers and uncached web fonts flash fallback glyphs. *Mitigation*: preload local subsetted font, await `document.fonts.ready` before painting, and visually calibrate `<text y>` in `pieces_sheet.png` / `pieces_small.png`.
3. **SVG `<symbol>` shadow clipping & `<defs>` ID collisions**: Blur shadows can clip at symbol bounds, and duplicate IDs across themes/trays break fills. *Mitigation*: use generous filter regions (`-25%` to `150%`), `overflow="visible"` on piece symbols, and theme-scoped IDs.
4. **Coordinate mapping, z-order & upright glyphs under board flip**: Mixing 180° board rotation with pointer hit-testing (`0.48 * cell`) and upright piece characters is error-prone. *Mitigation*: rotate only the board SVG layer during flip while interpolating piece positions upright, and map pointer coordinates via SVG viewBox projection.
5. **Idle CPU vs. smooth animations**: A permanent `requestAnimationFrame` loop wastes CPU. *Mitigation*: demand-driven `js/ui/anim.js` scheduler that runs `rAF` strictly while active tweens exist and halts when idle.

## Deviations from DESIGN.md
- **Tech Stack Override (User-directed)**: Replaced Rust (`eframe`/`egui`/`resvg`) with plain HTML + CSS + JavaScript ES modules + inline SVG, served locally via `python -m http.server 8000`. All visual specs (§5, §6, §7, §8, §10, §12, §14, §15) remain identical.
- **File label margin adjustment**: Moved top/bottom file labels from `y=78` / `y=1072` (size `30`) to `y=60` / `y=1093` (size `26`) because pieces on ranks 0 and 9 (`r=44` + wall thickness `+5`) visually overlapped the labels in `start_position.png`.
- **Perpetual-check adjudication**: Out of scope for v1 rules; 3-fold position repetition is adjudicated as `DrawRepetition` (same position + side to move 3 times).
- **Voice TTS (`edge-tts`) legal/ToS note**: `tools/gen_voice.py` uses `edge-tts` (Microsoft's online read-aloud service, unofficial API) once offline to generate `assets/voice/*.mp3`. Suitable for personal use; if ever distributed publicly or commercially, replace the MP3s in `assets/voice/` with licensed voice recordings or self-recorded audio using the same filenames and `manifest.json`.
- **Voice silence trimming**: Trimmed leading silence (`|x| > 0.01`, `-15 ms`) and trailing silence (`+120 ms` tail with `60 ms` fade-out) in `js/audio/voice.js` on decode, reducing padded `1.87–2.45 s` MP3s to crisp `0.47–1.32 s` clips and driving `checkmate2` (`承讓`) scheduling from the trimmed duration of `checkmate_1` (`將死`).
- **Offline AI architecture (`js/ai/`)**: Built a dedicated allocation-free `Int8Array(90)` move generator (`movegen.js`, verified identical to `XiangqiRules` on PERFT 1–3) + Negamax alpha-beta with iterative deepening, 64-bit Zobrist hashing (two `Uint32`s, BigInt-free), `2^20` replace-by-depth TT, MVV-LVA + 2 killers + history, quiescence search (depth 6), and check extensions, reaching ~2.4M nps at depth 5. Runs in an ES Module Web Worker (`worker.js`) with automatic chunked `setTimeout` main-thread fallback (`client.js`).
- **Voice Yunyang EQ warmth (`eqBoost: 2`)**: Measured processed spectral centroid of Yunyang (`2342 Hz`) was `1.32x` Yunjian (`1774 Hz`, > 1.25x), so added per-file `"eqBoost": 2` (+2 dB lowshelf at 160 Hz) for `check` and `capture` in `assets/voice/manifest.json`.
- **Pikafish strength levels & repetition authority**: Pikafish 2026-09-06 (`Pikafish-Windows-x86-64-universal.exe` + `pikafish.nnue`) does not expose `Skill Level` or `UCI_Elo` UCI options, so difficulty scaling uses `depth`, `movetime_ms`, and `MultiPV` safe window selection (`js/ai/levelsPikafish.js`). Pikafish applies computer repetition rules internally, while the app's own 3-fold repetition rule (`XiangqiRules.status`) remains the sole authority for game results.
- **Review mode state separation & O(1) snapshots**: `Board` maintains an immutable-per-ply `snapshots` array (`fen`, `sideToMove`, `move`, `captured`, `gaveCheck`, `isCheckmate`, `capturedByRed`, `capturedByBlack`) alongside `history`. Reviewing an older ply constructs a read-only display board in `BoardView` without mutating the live `Board`, so background AI replies never overwrite `viewPly`.
- **Deterministic end-of-game cinematics (`js/fx/endFx.js`)**: All animation (SVG swords/flag/crack/ink-wipe/seal + Canvas 2D seeded particles) is a pure function `render(t)` of elapsed ms `t`, enabling reproducible `window.__fxSeek(ms)` captures, zero per-frame allocations, and automatic rAF shutdown (0 idle callbacks) once settled. Removed redundant `<link rel="preload">` on the subset font in `index.html` to prevent unused-preload warnings on utility pages (`?effects`).

- **Cờ Úp `REVEAL_ON_CAPTURE = true`**: Khi một quân úp bị ăn, nó được lật công khai và trừ khỏi bảng quân úp còn lại (theo chuẩn phổ biến trên pychess/chessprogramming). Có thể đổi bằng hằng số `REVEAL_ON_CAPTURE` trong `js/jieqi/rules.js`.
- **Cờ Úp không cho đi lại (Undo / Continue from here) khi đấu máy hoặc online**: Tránh việc người chơi lật thử quân rồi đi lại để xem trước quân úp. Chế độ Hai người trên cùng máy vẫn cho phép đi lại.
- **Máy chủ online 1 cổng duy nhất (`server/index.js`)**: Dùng đúng 1 thư viện ngoài (`ws`, MIT), dùng chung trực tiếp `js/rules.js` và `js/jieqi/rules.js` để thẩm định nước đi và giữ `_secret` của Cờ Úp hoàn toàn phía server.
- **Online server CSP (`server/index.js`)**: Enforces `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' ws: wss:; worker-src 'self'; frame-ancestors 'none';` alongside `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, and `Referrer-Policy: no-referrer`. `'unsafe-inline'` on `style-src` is retained for dynamic inline CSS custom properties and SVG styles.
- **Save / Export / Import & Jieqi Secret Policy (`docs/FORMATS.md`)**: Exports (`.xqgame.json`, `.pgn`, `#/replay?g=...`) contain strictly public history (revealed pieces only; `secretLocal` and `guestId` are always stripped). Continuing an imported/truncated Jieqi game deals remaining pool identities uniformly at random via `dealRemainingPool(board, pool, rng)`. Local/AI autosave stores `secretLocal` in browser IndexedDB (`xq_games_v1`) for exact resume (acceptable for single-player local play); online games never autosave. Library cap is 200 games (`needsPrune` prompt before deleting oldest); share-link payload cap is 6000 chars with a 256 KB decompressed zip-bomb cap.
- **Mobile & Touch Layout (`docs/MOBILE_DESIGN.md`)**:
  - **Zero DOM re-parenting across `desktop` / `side` / `stack`**: `.sheet-host` wraps the move list, Jieqi pool, and options inside `#side-panel`. On `desktop` and `side`, `.sheet-host` / `.sheet-scroll-body` / `.sheet-pane` use `display: contents` with explicit CSS `order` so desktop retains its exact vertical order (`M8 <= 0.27%` pixel diff). On `stack`, `#side-panel` uses `display: contents` so player cards place into `opp`/`me` grid areas while `.sheet-host` becomes a `position: fixed` transform-only bottom sheet (`visibility: hidden` when closed).
  - **Mobile controls attribute separation (`data-maction`)**: `.mobile-controls-bar` uses `data-maction` instead of `data-action` so existing desktop `[data-action="..."]` selectors remain unique in Playwright strict mode.
  - **Compact board `viewBox`**: For board widths `< 480 px` (non-desktop), `BoardView.setCompactMode(true)` switches `viewBox` to `73 73 904 1004` (8 units beyond outer disc radius 44), hides `.board-layer-labels`, and adds a 2 px frame border; `clientToBoard()` maps through the active `viewBox`.
  - **Height-constrained stack chrome**: In `stack` layout, compact chrome row heights (`44/40/32/40/48`) activate whenever `h <= 600` OR `(h - 220 - safeV) * (1050/1150) < availW * 0.97` (e.g. `768x1024` portrait tablet) so board width always meets `>= 96%` of viewport width.
  - **Coarse-pointer cinematic performance (`js/fx/endFx.js`)**: Under 4× CPU throttle, per-frame CSS/SVG filters (`boardSvg.style.filter`, `generalEl.style.filter`, `fx-sword-shadow`, `fx-tear-filter`, `fx-seal-rough`) and continuous `pushScale` forced full re-rasterization of the `feTurbulence` wood SVG (`p95 = 133 ms`). Disabling those per-frame filters, capping particles at 50%, and capping canvas DPR at `1` on coarse pointers brought 4×-throttle `fx_p95` down to `50 ms` (`<= 60 ms` target) with desktop cinematics untouched.
  - **Direct `pointerup` tap handling on `MoveStrip` chips**: Horizontally scrollable touch strips can swallow synthesized `click` events after quick taps; handling short touch taps (`dist < 10 px`) directly on `pointerup` makes chip review instant and reliable.
- **Mobile Online Dialogs Diagnosis (`fix/mobile-online-dialogs`)**:
  - **Root cause 1 (overflow & left-clipping in Phòng riêng → Nhập mã)**: `.code-boxes` had `grid-template-columns: repeat(6, 1fr)` without `minmax(0, 1fr)` and `.code-box` (`<input type="text">`) lacked `min-width: 0; width: 100%`. Each `<input>` kept its default HTML `size="20"` intrinsic width, inflating `.modal-card` to ~1,470 px inside the flex-centered `.modal-backdrop` and clipping both edges on phones. Fixed with `display: flex; gap: clamp(4px, 1.5vw, 10px)` + `flex: 1 1 0; min-width: 0; width: 100%; aspect-ratio: 1 / 1.25; font-size: clamp(20px, 6vw, 28px)` and `max-width: 100vw; overflow-x: hidden` on mobile bottom-sheet modals.
  - **Root cause 2 ("Thử lại" / "Cài đặt" visible while online)**: `.mode-offline-actions` declared `display: inline-flex` without a `.mode-offline-actions[hidden] { display: none !important; }` rule, overriding the UA `[hidden]` style even when `onlineInfo.ok === true`.
  - **Root cause 3 (landscape & soft-keyboard clipping)**: Online modals had no landscape centered-panel media rule (`max-height: 92dvh`, safe-area padding) and `--vvh` was only updated inside `LayoutManager` (game screen), not on Lobby/Mode screens. Moving `--vvh` / `--app-h` / `?safe` sync to a shared global listener in `js/main.js` keeps every modal responsive to soft-keyboard shrinks on all screens.
- **Compact Side Panel & Full-Swap Analysis Redesign (`feat/compact-panel`)**:
  - **Intentional Desktop M8 Re-baseline**: The default desktop side panel (`320 px`) was redesigned to eliminate panel-level scroll and move secondary controls into the `"⋯"` overflow menu. Before re-baselining `preview/mobile_baseline/*.png`, we verified that the **board area itself** (`0 .. width - 340`) stayed within `<= 1.5%` pixel diff against the pre-redesign baseline (`960×680`: `0.02%`, `1180×780` start: `0.01%`, `1180×780` midgame: `0.13%`), then re-baselined all 12 desktop M8 PNGs (`M8 max_diff_pct = 0.31%`).
  - **P4 Local 2-Player Integrity Exception**: Live single-position analysis (`250 ms` debounce, Pikafish `1000 ms` / JS depth 5) is allowed in live **local 2-player Cờ Tướng** games (study/teaching on one device) and unfinished local archive deep links, while live **AI**, live **Online**, unfinished AI/Online archives, and **Cờ Úp** everywhere remain strictly hidden/blocked.
  - **Zero DOM Re-parenting for Full-Swap Analysis**: `.analysis-pane-host` remains inside `.sheet-pane[data-spane="analysis"]`. Opening analysis toggles `.side-panel.is-analysis-open` on desktop/side (hiding `.compact-panel-body`, `.compact-panel-footer`, and other panes) and opens `BottomSheet` to `'full'` on tab `'analysis'` on phone `stack` layout.

- **Vietnamese Traditional Move Notation (`feat/traditional-notation`)**:
  - **Display-Only Layer**: Coordinates (`"h2e2"`) remain the sole canonical representation across storage, export/import, online WebSocket protocol, and engine UCI calls. Traditional notation is computed strictly on-demand from `(boardBefore, iccsMove)` via `js/notation/traditional.js` + `js/ui/moveText.js` (with an 800-entry LRU cache on `variant|fen|iccs` for `< 25 ms` 150-ply toggles under 4× CPU throttling).
  - **Additive Setting (No Schema Bump)**: Added `notation: 'traditional' | 'coord'` (default `'traditional'`) to `xq_settings_v1` (`v: 2`) without bumping the schema version so existing profiles migrate seamlessly.
  - **Container-Query Width Cutoff (`112 px`)**: `.move-chip` uses `container-type: inline-size` with `@container (min-width: 112px)` to render full form (`Pháo 2 bình 5`) when wide and short form (`Pháo 2=5`) when narrow, with `title` always showing the alternate form (`h2e2`) and `aria-label` speaking natural Vietnamese (`"Pháo, cột 2, bình 5"`).
  - **Desktop M8 Preserved Without Re-baseline**: Default notation change kept desktop M8 pixel diff at `0.693%` (`<= 1.5%`) on Chromium and `0.0%` on WebKit, so no M8 baseline reset was required.
  - **Jieqi No-Peeking Guarantee**: Covered pieces always use their public fake role (starting square) in traditional notation, verified byte-identical across 20 secret shuffles.
